# ChatGPT 連携の設定手順（専用の GPT を作る）

ChatGPT から English Stock に単語・フレーズを**追加だけ**できるようにします。
アプリから ChatGPT（AI）を呼び出すことはありません（ChatGPT → アプリ の一方通行）。

> 必要なもの：ChatGPT の有料プラン（Plus など。GPT を自分で作る機能が必要）

---

## 1. アプリで連携キーを発行する

1. English Stock を開く → 右上の **⚙（設定）** → **ChatGPT連携**
2. **連携キーを発行する** を押す
3. 表示された `es_...` で始まるキーを **コピー**（この画面を閉じると二度と表示されません）

> キーは人に見せたり、ChatGPT のチャット欄に書き込んだりしないでください。
> 漏れたかもしれないときは、同じ画面の **連携をやめる** で無効にし、発行し直してください。

## 2. ChatGPT で GPT を作る

1. ChatGPT（ブラウザ版がおすすめ）→ 左のメニュー **GPT** → 右上の **＋ 作成**
2. **構成（Configure）** タブを開き、次のように入力する
   - **名前**：English Stock
   - **説明**：English Stock の単語帳に単語・フレーズを追加します
   - **指示（Instructions）**：下の「GPT の指示」をそのまま貼り付ける
3. 下のほうの **アクション（Actions）** → **新しいアクションを作成する**
   - **スキーマ**：**URL からインポート** を押し、次の URL を入れる
     `https://shun222hgdn-cmd.github.io/english-stock/chatgpt-openapi.json`
   - **認証（Authentication）**：歯車 → **API キー** → 認証タイプ **Bearer** → API キーに、1でコピーした連携キーを貼り付けて保存
   - **プライバシーポリシー**：自分だけで使う場合は空欄で大丈夫です
4. 右上の **作成 / 更新** → 公開範囲は **「私だけ」**（自分専用）を選ぶ

## 3. 使ってみる

作った GPT を開いて、たとえばこう話しかけます。

> 今日のレッスンの単語、しゅんのフォルダに追加して。
> resilient＝回復力のある、break the ice＝場を和ませる

初めて使うときは「English Stock と通信してよいか」の確認が出るので、**許可** を押します。
追加が終わると、何件追加したか・追加しなかったもの（登録済みなど）を教えてくれます。
アプリを開くと、単語帳に入っています（開いていた場合は、いったん別のアプリに切り替えて戻ると更新されます）。

## GPT の指示（Instructions にそのまま貼り付け）

```
あなたは英語学習アプリ「English Stock」の単語帳に、英単語・英語フレーズを追加するアシスタントです。

■ できること
- listFolders：追加先のフォルダ一覧を見る
- addStocks：単語・フレーズを追加する（1回50件まで）
- 削除・編集・閲覧（登録済みの単語の一覧を見ること）はできません。頼まれても「できない」と伝えてください。

■ 追加するときの手順
1. 追加先のフォルダが分からないときは、listFolders で一覧を確認し、ユーザーに選んでもらう。フォルダが1つだけならそれを使う。locked が true のフォルダには追加できない。
2. 各項目について、次を用意する。
   - english：英単語・英語フレーズ（ユーザーが書いた綴りをそのまま。明らかな誤字は確認してから直す）
   - japanese：自然で短い日本語訳（ユーザーが訳を書いていればそれを使う）
   - category：単語なら word、フレーズ（2語以上）なら phrase
   - part_of_speech：単語のときだけ。名詞・代名詞・動詞・形容詞・副詞・助動詞・前置詞・冠詞・接続詞・間投詞 から1つ。迷うときは付けない
   - note：ユーザーがコメントを指定したときだけ入れる。例文は入れない
3. 追加する内容を短い表で見せ、ユーザーの「OK」を待ってから addStocks を呼ぶ。
4. 結果（追加した件数、skipped とその理由）を日本語で短く報告する。

■ 注意
- ユーザーの連携キーやパスワードを聞いたり、表示したりしない。
- エラーが返ったら、error の内容をそのまま分かりやすく伝える。
```

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「連携キーが正しくないか、無効になっています」 | アプリの ⚙ → ChatGPT連携 でキーを発行し直し、GPT のアクションの認証に貼り直す |
| 「鍵がかかっているため、ChatGPT からは追加できません」 | アプリでそのフォルダの鍵を外すか、別のフォルダを指定する |
| 追加したのにアプリに出ない | アプリを再読み込みする／正しいフォルダを開いているか確認する |
| もう使わない | アプリの ⚙ → ChatGPT連携 → **連携をやめる**（GPT を消さなくても、追加できなくなります） |
